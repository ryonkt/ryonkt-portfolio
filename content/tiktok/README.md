# 非エンジニアのためのClaude Code最強化ツール図鑑（TikTok投稿計画）

> コードは書けないけど Claude Code は毎日使っている——そんな人に向けて、トークン削減・自動連携などの"神ツール"を **1本1テーマ** で届けるカルーセル投稿シリーズです。

- **ターゲット**: 自分でコードは書けないが Claude Code を使っている非エンジニア
- **形式**: テキストカルーセル（画像スワイプ／添付のバズ投稿と同型・撮影不要）＋各投稿に短尺動画への転用フック付き
- **本数**: 全5本（看板1本＋深掘り3本＋保存版総集編1本）
- **元ネタ**: Sage AI「Start Using These GitHub Repos for Claude Code Today」（保存583・シェア83の高保存バズ投稿）の勝ちパターンを踏襲
- **生成方式**: オーケストレーション = Opus 4.8 / 各原稿の生成・検証 = Sonnet 5（マルチエージェント並列）

## 勝ちパターン（全投稿共通の型）

1. **スライド1（フック）** … 数字入りの強い見出し＋「単体運用はもう古い」系の煽り
2. **スライド2〜N（各ツール）** … 名前 / 一言概要 / 🔥最強ポイント（具体数字）/ 👶非エンジニアに何が嬉しいか / 導入難易度
3. **最終スライド（CTA）** … 「まず何から？」の結論＋保存・フォロー誘導

> ⚠️ 数値（削減率など）はすべて開発者・利用者の**報告ベースの目安**。投稿内では「〜と言われる」「報告がある」と伝聞表現を徹底し、断定・誇張を避けています。

## 運用Tips

- 1枚目の見出しは3秒で内容が伝わる文字量に絞り、数字（90%減・49倍・14%減など）は大きめフォントで強調する。
- 数値には必ず「〜と言われる」「〜という報告がある」の伝聞表現を使い、一次情報元や自分の検証結果である旨を最終スライドか概要欄に軽く添える（誇張・断定を避ける）。
- 各投稿の最終スライドは「保存してね」「フォローすると残り◯本も届くよ」など**次のアクションを1つだけ**明示する（複数CTAを出さない）。
- キャプション冒頭にもフック文＋「#04まで保存版あり」のようにシリーズ内の位置づけを書く。
- コメントで「自分でも試せますか？」系が来たら固定コメントで導入手順の超要約を返す。
- 投稿直後30分はコメント返信に張り付き、初速のエンゲージメントを稼ぐ（初期評価に効く）。
- 5本すべて投稿し終えたら04（総集編）を固定投稿にし、新規訪問者が一気見できる導線を作る。
- 配色・フォント・スライド構成を5本通して統一し、一目で「あのシリーズだ」と認識されるブランド感を作る。
- 画面キャプチャ（ビフォーアフター）を1枚以上入れると「本当に使えそう」という信頼感が上がる。
- 週2本ペースを崩さないことを最優先。04公開後は反応の良かった回の続編や実演動画で間を埋める。

## デザインの基本方針（全投稿共通）

- 背景はダーク系（黒〜濃紺）＋アクセントカラー1色（オレンジ or ライムグリーン）で統一。文字は白＋アクセントの2色運用。
- フォントは太字ゴシック（見出し）＋読みやすい本文フォントの2種のみ。
- 1スライド＝スマホ1画面で読み切れる文字量（3〜4行目安、1行20文字前後で改行）。
- 専門用語（プロキシ／MCP／フック／CLAUDE.md／PR など）は初出時に必ずカッコ内で一言補足。
- 各スライド右下に「01/05」的なページネーションを入れてシリーズ感を出す。
- Canva等のテンプレートを1つ作り、文言だけ差し替えれば5本量産できる。
