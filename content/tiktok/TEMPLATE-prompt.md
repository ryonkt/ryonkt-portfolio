# カルーセル生成 固定テンプレート（デザインは変更しない）

> 運用ルール：**このファイルの「A. 固定デザイン指示」は毎回そのまま使い、絶対に書き換えない。**
> 新しい投稿を作るときは **「B. 差し替えブロック」の値だけ** を変える。
> AIには「A ＋ Bを埋めたもの」を丸ごと1回で渡す。

---

## A. 固定デザイン指示（毎回コピペ・改変禁止）

```
あなたは一流のエディトリアルデザイナーです。以下の仕様で、TikTok用カルーセルを
「1つの自己完結HTMLファイル」として出力してください。指定枚数のスライドを横スワイプで
見られる形にし、CSSは全てインライン、外部フォント・画像リンクは使わない
（フォントはOS標準の明朝・ゴシックスタックで指定）こと。

■ ターゲット：非エンジニアのClaude Codeユーザー。
■ 判型：各スライド 9:16 の縦型。1枚1メッセージ。スマホ1画面で読み切れる文字量に絞る。

■ 配色（モノトーン＋差し色1つ）
背景=温かいオフホワイト #FAF9F5／文字=ほぼ黒 #1F1E1C／補助=グレー #6B6862／
アクセント=テラコッタ #CC785C（1画面に1箇所だけ）／罫線=#E8E5DE。
グラデ・影・光沢・絵文字・吹き出し・バッジ・囲み枠は禁止。区切りは1pxヘアラインのみ。
ライト／ダーク両テーマ対応（ダークは背景#1C1B19・文字#EDEBE4・アクセント#E0997B）。

■ タイポグラフィ（最重要・混植で強いインパクト）
明朝体とゴシック体を1画面内で混ぜる。
・名詞／キーワード／ツール名／数字＝極太ゴシックで「大きく」。画面の主役。
・助詞／語尾／つなぎの文＝明朝で控えめ・小さめ。脇役。
・主役と脇役でサイズ差を2〜3倍つけ、主役の名詞は改行して独立行に置く。
★スライド1（フック）では必ず「Claude Code」を画面最上部に、画面幅いっぱいの
　最大サイズ極太ゴシックで独立配置する。視聴者が最初の1秒で“自分に関係ある話”だと
　分かることを最優先する（反応を左右する最重要ポイント）。
ゴシック=font-family:"Hiragino Kaku Gothic ProN","Noto Sans JP",sans-serif; font-weight:900。
明朝=font-family:"Hiragino Mincho ProN","Noto Serif JP",serif。
各スライド右下に明朝の薄いグレーでページ番号。

■ 各スライドの型（この構造も固定）
・スライド1（フック）：最上部にゴシック最大「Claude Code」→2番手の見出し（名詞ゴシック大＋
　明朝小の混植）→下にテラコッタ強調フレーズを1つだけ含む明朝小の補足。
・ツール紹介スライド：左上にゴシック極太特大の連番→ゴシック太大でツール名→明朝小グレーで
　1行説明→ヘアライン→「効果／うれしさ／導入」の3項目（ラベル=小さな大文字ゴシック、
　値=明朝、効果の数字だけゴシック極太特大）。
・最終スライド（CTA）：上部に小さな大文字ゴシックのラベル→明朝＋ゴシック混植の手順リスト
　（各行の間にヘアライン、ツール名はゴシック大）→明朝極小グレーの注記→ミニマルなボタン2つ
　（塗り「保存」＋枠線「フォロー」、文字はゴシック）。

■ トーン＆マナー：数値は必ず「〜と言われる」「報告あり」等の伝聞にし、断定・誇張を避ける。
■ 出力：完成HTMLを1ファイルで。横スクロールのスクロールスナップで配置、各カードは
　角丸6px・1px罫線・大きめ余白。説明文は付けずコードのみ返す。

――― 以下、今回の中身 ―――
```

## B. 差し替えブロック（毎回ここだけ書き換える）

Aの直後にそのまま続けて貼る。`《 》`の中だけ埋める。

```
テーマ：《この投稿のテーマ。例：コンテキスト圧縮ツール2選》
スライド枚数：《フック1＋ツール数＋CTA1。例：4》

【スライド1｜フック】
最大ゴシック（主役・固定）：Claude Code
2番手の見出し：《名詞をゴシック大・つなぎを明朝小で。例：、毎回コードを[全部読み]してるかも。》
補足（明朝小・[ ]内だけテラコッタ強調）：《例：読ませ方を変えた人は複雑なタスクで[最大49倍のムダ]が消えたと報告しているらしい。》

【ツールスライド（ツールの数だけ繰り返す）】
・連番：《01》／ツール名：《作者 / ツール名》
 一言（明朝小）：《そのツールが何か1行で》
 効果（数字だけ特大）：《例：最大49倍減》＋《補足文。例：の報告も（条件次第の参考値）》
 うれしさ：《非エンジニアに何が嬉しいか》
 導入：《かんたん／ふつう／むずかしい＋一言》

【最終スライド｜CTA】
ラベル：《例：まず何から》
手順リスト（ツール名はゴシック大）：《例：① まず[repomix]で一式渡す ／ ② 慣れたら[code-review-graph]で地図化》
注記（明朝極小）：数字は報告ベースの目安で、環境により変わります。
```

## 使い方
1. 上の **A** をコピー
2. すぐ下に **B** をコピーして`《 》`を今回の内容で埋める
3. AとBをつなげて、そのままAIに1回投げる → デザイン一定のカルーセルHTMLが出る
